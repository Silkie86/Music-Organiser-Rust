# Music Organiser (Rust)

The Rust rebuild of [Music Organiser](https://github.com/Silkie86/Music-Organiser): one offline, native app for your
songs, sounds, MIDI ideas and plugins. Windows first, macOS and Linux ready.

Work in progress. The plan is in [docs/spec.md](docs/spec.md), the working rules are in [CLAUDE.md](CLAUDE.md), and
[docs/getting-started.md](docs/getting-started.md) says how to run it on your PC.
